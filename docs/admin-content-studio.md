# 后台内容工作区规格

## 目标

后台运营人员只需进入“内容管理”即可维护官网内容。站点设置、导航、首页区块、业务卡片、资质伙伴、独立页面、页面模块和图片位都保存到同一份内容包，无需修改前端源码。

## 内容边界

- `HomeContent`：品牌、全站导航、首页全部区块、联系信息、页脚、首页图片。
- `Subpage`：独立页面的导航名称、标题、摘要、主图、指标、列表、步骤、页面模块、模块图片和模板图片位。
- 图片只能通过后台上传，并以站内路径保存；正文与链接由对应内容表单保存。
- 动效、无障碍标签和布局选择属于展示实现，不作为运营文案暴露；业务可见标题、说明、列表和图片均有内容字段或安全回退字段。

## 信息架构

- 内容管理：单一工作区，按“基础设置、首页编排、解决方案与动态、产品中心、资质与伙伴、独立页面”分区。
- 账号管理：独立系统功能。
- 不保留历史后台目录或兼容跳转。平台入口固定为 `/admin/content`、`/admin/system/users` 和 `/admin/login`。

## 接口契约

内容工作区继续使用 `POST /api/admin/content` 提交完整 `SiteContentBundle` 与版本号。该接口保留冲突检测、站内图片路径校验和历史默认值兼容，不改变已有前台读取方式。

## 验收条件

1. 后台侧栏只保留“内容管理”和“账号管理”两项主入口。
2. 内容管理页可直接切换六类内容，不发生页面级导航。
3. 每类内容的标题、文本、链接和图片字段均可保存到现有内容包。
4. 历史后台地址仍可到达统一工作区。
5. TypeScript、lint、生产构建通过；未登录访问仍跳转登录页。
