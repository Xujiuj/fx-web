# 内容配置化规格

## 目标

管理员无需修改前端源码，即可通过后台维护现有站点的页面内容、导航菜单与页面图片。内容保存到 `SiteContent`，并在所有前台页面刷新后生效。

## 范围

- 首页：品牌、菜单、横幅、关于我们、能力路径、解决方案、动态、产品、资质、伙伴、思考区、联系信息和页脚。
- 子页面：页面基础信息、模块、条目、链接和每个模板使用的媒体资源。
- 图片：上传站内图片，或从已上传的站内媒体中选择；保存时只接受站内路径。
- 页面：管理员可新增、编辑、删除现有布局类型的页面，并通过菜单链接它们。

## 不在范围内

- 任意拖拽式页面搭建器或运行时执行自定义前端代码。
- 外链图片、外链脚本和未受限制的 HTML 注入。
- 删除已上传的物理媒体文件。

## 内容契约

- `HomeContent` 和 `Subpage` 是唯一的前台内容源；数据库内容缺失时使用项目默认内容。
- 每个 `Subpage` 可选 `media` 键值表，键为模板约定的媒体位，值为站内图片路径。
- 每个首页关于我们页签保存自己的图片和展示标签；能力路径保存自己的背景图片。
- 内容保存继续使用现有的乐观并发版本号；冲突返回最新内容包。
- 服务端在 API 边界校验所有媒体路径、页面 slug、数组结构和媒体表值。

## 管理后台体验

- 页面管理表单提供基础信息、模块条目和媒体资源列表。
- 首页管理表单提供所有首页区块及其图片字段。
- 媒体字段复用现有上传组件，显示预览、上传错误和移除操作。
- 保存、冲突、空状态和上传失败都必须有明确反馈。

## 验收标准

1. 管理员可在后台修改任意现有菜单标签、链接和二级菜单，无需前端改动。
2. 管理员可修改每个首页区块与每个子页的文案、列表和图片，并在前台看到变化。
3. 由页面模板使用的图片都从内容配置读取；未配置时才使用兼容默认值。
4. 非管理员、外链图片路径、无效 slug 和无效内容包均被 API 拒绝。
5. 内容冲突不覆盖其他管理员的保存结果。
6. 类型检查、ESLint、生产构建和浏览器中的核心后台编辑流程通过。

## 验证命令

```bash
npx tsc --noEmit
npm run lint
npm run build
```

## 边界

- 始终：校验后台输入，只持久化站内图片路径，保留现有默认内容作为回退。
- 先确认：新增依赖、修改 SQLite 表结构、修改部署工作流。
- 禁止：提交凭据、接受远程 HTML/脚本、覆盖其他未提交的用户改动。
